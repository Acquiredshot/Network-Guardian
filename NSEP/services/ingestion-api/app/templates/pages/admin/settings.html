ENVIRONMENT-MANAGED NSEP has no settings-write API. Configuration is set per-service through environment variables.

This page never displays secrets (API tokens, passwords) and does not let you change configuration from the browser -- that would require restarting the relevant container with new environment variables.

  • security-workersZAMMAD_API_TOKEN, ZAMMAD_GROUP_ID, ZAMMAD_CUSTOMER_ID, NETWORK_GUARDIAN_*, AZURE_OPENAI_*ENV VARS

See docker-compose.yml and each service's .env.example in the repository. Live reachability of the values above is on Administration → Integrations.
