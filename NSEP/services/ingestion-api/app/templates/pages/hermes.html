CLIENT, NOT DATA SOURCE Hermes Agent connects to NSEP's MCP server -- it does not send telemetry back to NSEP.

Hermes is an external agent that Nous Research ships. When configured, it calls NSEP's read-only MCP tools (get_event, get_incident, search_events, get_detection_summary, get_risk_score, get_incident_timeline, investigate_incident) over the Model Context Protocol. NSEP has no channel for Hermes to report its own investigations, actions, or activity back, so those pages are placeholders.
