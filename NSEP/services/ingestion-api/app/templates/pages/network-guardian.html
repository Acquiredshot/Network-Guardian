OUTBOUND ONLY NSEP pushes incidents to Network Guardian's Event Fabric. It never reads Network Guardian's own data.

The network_guardian integration is a fire-and-forget HTTP POST to /api/event-fabric/intake on every new incident. There is no query API back into Network Guardian, so device inventory, network events, threat detection, and investigations are not available from this dashboard.
