  1. Source submits an event to NSEP's HTTP API.
  2. API persists acceptance in PostgreSQL and publishes to RabbitMQ.
  3. Celery worker consumes, detects, scores, and persists results; Redis is its result backend.
  4. New incidents are pushed outward to Guardian Event Fabric and optionally Zammad.
  5. Dashboards and read-only MCP tools query NSEP's API; Hermes is an external MCP client.
